Emerald .mrld Syntax

Emerald is a terminal-native syntax for structured notes. Single-character prefixes, indentation hierarchy, tables, kanban, transclusion, AI commands, and smart properties — all faster to type than Markdown.

Contextual Auto-Dates (Markdown can't do this)

Task lines auto-detect dates from natural language — no @due() needed:

> Buy milk tomorrow
> Ship feature next week
> Review PR on Friday
> Deploy on 2026-06-01

Words detected: tomorrow today next week monday—sunday next monday and ISO dates YYYY-MM-DD. The due date badge appears automatically in the preview.

Tables

Pipe-delimited rows. First line is the header. Optional separator line with --- in each cell.

| Name      | Role       | Status   |
|-----------|------------|----------|
| Sarah     | PM         | Active   |
| James     | Engineer   | Inactive |
| Maya      | Designer   | Active   |

Kanban Boards

Start a board with ~ column | names ~. Add items with [ColumnName] prefix.

~ TODO | DOING | DONE ~
[TODO] Write API docs
[TODO] Set up CI pipeline
[DOING] Fix login timeout
[DONE] Ship v2.0

AI-Native Commands

Lines with @ai render as AI command blocks. An AI agent can detect and execute them:

@ai analyze sentiment
@ai extract action items
@ai generate summary
@ai relate to: "Project Alpha"

AI Memory Tags

Use @memory to mark content the AI should remember across sessions:

@memory important The auth flow uses JWT + refresh tokens
@memory todo Migrate billing to Stripe by Q4
@memory fact Our biggest customer is Acme Corp (40% rev)

Renders with a yellow MEM badge — AI agents can index these across all notes for persistent context.

Calendar Events

Lines starting with @YYYY-MM-DD render as calendar entries:

@2026-06-01 Q3 planning meeting
@2026-06-15 Ship v2.0 release
@2026-07-01 Board presentation

Transclusion

Embed another note inline with {{"{{note:title"}}}}. The referenced note renders inside a purple bordered card:

# Weekly Standup
h2: Project Alpha
{{"{{note:project-alpha-status"}}}}
h2: Project Beta
{{"{{note:project-beta-notes"}}}}

Perfect for dashboards, roll-up notes, and cross-referencing.

Indentation Hierarchy

Two spaces or one tab = one level deeper:

Bold Text

**double asterisks**  // classic Markdown
__double underscores__ // shorter
!single bangs!         // fastest

Directives (note-level commands)

Lines starting with // change how the entire note renders.

//whitepaper

Transforms the note into a formal document: white background, dark serif text, justified paragraphs, centered title. Perfect for reports, proposals, and documentation.

//whitepaper
# Q3 Strategy Proposal
h2: Executive Summary
@ This document outlines our strategic direction for Q3 2026...

//terminal

Opens an opencode terminal session at the bottom of the screen, pre-loaded with the current note as context. The terminal has access to the full note content — you can type build this app and it processes your note as the specification.

//terminal
# My App Spec
> User authentication with JWT
> REST API for CRUD operations
> PostgreSQL database schema
@ Then type "build this app" in the terminal.

Terminal commands: help context tasks explain build clear exit

Self-Opening .mrld Files

When you export a .mrld file, it's a self-contained HTML document. Double-click it in any OS — it opens in your browser and renders the Emerald content. The complete parser and styles are embedded in the file. No app needed to view.

Why Emerald Beats Markdown

  • Auto-dates — > buy milk tomorrow auto-adds the due date. Markdown can't parse natural language.
  • Tables & kanban — first-class semantic blocks, not just styling conventions
  • Transclusion — {{"{{note:title"}}}} embeds notes inside notes. Dashboards, roll-ups, cross-references.
  • Directives — //whitepaper for formal docs, //terminal opens an AI terminal with note context
  • AI-native — @ai commands and @memory tags are machine-detectable
  • Self-opening .mrld — exported files open in any browser, no app needed
  • Smart properties — frontmatter + inline [K: V] for structured metadata
  • Comments that vanish — / private note hidden in Preview, visible while editing
