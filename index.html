Emerald Syntax .mrld

Emerald is a fast, terminal-native syntax for notes. Single-character prefixes and indentation hierarchy make it the fastest way to write structured notes. .mrld files are plain text — readable in any editor.

AI-Native Commands

Lines starting with @ai are rendered as AI command blocks. These are first-class citizens — an AI agent can detect and execute them directly from your notes.

@ai analyze sentiment
@ai extract action items
@ai generate summary
@ai relate to: "Project Alpha"

Each renders with a green accent bar and @ai label. Future: AI agents can hook into these to run commands against the note content.

Smart Properties

Frontmatter Block

YAML-like but faster. Open with --- at the top of a note, close with ---. Properties render as a metadata panel.

---
Project: Nexus
Due: 2026-06-01
Tags: [product, ai, format]
Priority: 9
---
# Q3 Planning
h2: Key Decisions
- Migrate backend to Rust

Inline Properties

Quick metadata in a single line. Wrap in [ ] with | separators.

@ Status update [Priority: P9 | Owner: Sarah | Due: Fri]

Or use tags without values: [blocked | needs-review | backend].

Indentation Hierarchy

Two spaces or one tab = one level deeper. No extra markers needed for children.

Meeting with Sarah
  > Discuss Q3 goals @due(Friday)
    - Revenue target: $2.4M
    ? What blockers exist?
  + Competitor analysis
    • Linear: 40% faster
    • Cursor: better UX
  = Owner: Sarah
  = Priority: High

Bold Text

Three syntaxes — use whichever is fastest:

**double asterisks**   // classic
__double underscores__  // shorter
!single bangs!          // fastest

Comments

Lines with / are hidden in Preview. Write reminders, TODOs, or private notes that stay invisible when sharing your screen.

Why Emerald Beats Markdown

  • Single-char prefixes: # > ? ! / + = @ — type fast, scan fast
  • Indentation IS hierarchy — one tab nests, no extra syntax
  • AI commands are first-class: @ai blocks an AI agent can detect and execute
  • Frontmatter and inline properties for structured metadata — both readable as plain text
  • Comments exist while editing but vanish in Preview — private notes, public rendering
  • .mrld files are plain text — works in vim, nano, VS Code, anywhere
