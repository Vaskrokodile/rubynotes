Emerald Syntax Guide .mrld

Emerald is a fast, intuitive syntax for writing notes — stored as .mrld files (just like Markdown uses .md). Designed to be quicker to type than Markdown while keeping everything readable as plain text. Use the Import / Export buttons to share .mrld files, or drag-and-drop them into the app.

Titles & Headings

Start a line with Title: or !! for a main heading (h1). Use h2:, h3:, h4: for subheadings.

Title: My Meeting Notes
!! Quarterly Review
h2: Agenda
h3: Action Items
h4: Follow-ups

Markdown equivalent: #, ##, ###, #### — Emerald saves keystrokes by using readable prefixes.

Bold / Emphasis

Three ways to bold text — pick whichever is fastest for you:

**double asterisks** — classic, familiar
__double underscore__ — shorter
!single bang! — fastest, one character per side

All produce bold text in the preview.

Lists

Emerald has four list types, each starting with a different symbol:

Standard List

- Buy groceries
- Call dentist
- Review PR

Task List

Start with > to create an actionable task with a checkbox. Add @due(date) to set a due date.

> Fix login bug
> Update dependencies @due(2026-06-01)
> Write unit tests @due(tomorrow)

Question List

Start with ? to mark open questions — great for meetings, research, and AI prompts.

? What's the timeline for Q3?
? Who owns the design review?
? Should we migrate to TypeScript?

Priority List

Start with ! (bang + space) to flag high-priority items. Renders with a HIGH badge.

! Fix production outage
! Security patch for CVE-2026
! Prepare board deck

Combining Syntax

You can nest inline formatting inside any block element:

h2: !Critical! Updates
- **Must read** before the meeting
> Review !security! patch @due(2026-05-30)
? Why is the __latency__ spiking?

Design Philosophy

Emerald beats Markdown because it optimizes for the most common note-taking patterns:

  • Headings use natural language prefixes (h2:) instead of counting # symbols
  • Tasks, questions, and priorities are first-class citizens — no need for nested Markdown + HTML + CSS
  • Multiple bold syntaxes let you choose what's fastest on your keyboard layout
  • Due dates are parsed natively so your task list doubles as a deadline tracker
  • Plain text is always readable — Emerald is designed to look clean even before rendering
