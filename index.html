Emerald .mrld — Complete Syntax Reference

Emerald is a terminal-native syntax for structured notes. Single-character prefixes, indentation hierarchy, native AI commands, and semantic blocks — all faster to type than Markdown. .mrld files are plain text, self-rendering HTML when exported.
