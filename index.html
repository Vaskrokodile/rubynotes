Emerald Syntax .mrld

Emerald is a fast, intuitive syntax for writing notes — stored as .mrld files (the equivalent of Markdown's .md). Single-character prefixes and indentation-based hierarchy make it faster to type than Markdown, while keeping plain text readable.

Bold / Emphasis

Three ways to bold text — use whichever is fastest:

**double asterisks** — classic Markdown familiar
__double underscore__ — shorter to type
!single bang! — fastest, one character

Indentation Hierarchy

One tab or two spaces = one level deeper. No need for list markers on every line when nesting under a parent.

Meeting with Sarah
  > Discuss Q3 goals
    - Revenue target: $2.4M
    ? What blockers do we have?
  + Competitor analysis
    • Linear: 40% faster
    • Cursor: better UX
  = Owner: Sarah
  = Priority: High

Tasks with Due Dates

Add @due(date) to any task for deadline tracking:

> Ship v2.0 @due(2026-06-15)
> Review security audit @due(tomorrow)

Comments

Lines starting with / are hidden in the Preview tab — keep private notes in plain sight while editing, invisible when presenting.

/ TODO: verify these numbers with finance
> Q3 revenue: $4.2M
> Q4 projection: $5.1M

Key-Value Properties

Use = for structured metadata at any indent level:

= Status: In Progress
  = Owner: Sarah Chen
  = Due: 2026-06-01

Toggles

Use + for collapsible sections. Click the summary to expand/collapse:

+ Implementation details
  - Uses WebSocket for real-time sync
  - Backed by SQLite
  - Rate limited at 100 req/s

Design Philosophy

Emerald beats Markdown because it optimizes for real note-taking:

  • Single-character prefixes: # > ? ! / + = — fast to type, easy to scan
  • Indentation is hierarchy — one tab nests under the parent, no extra syntax needed
  • Tasks, questions, warnings, toggles, and key-values are first-class citizens
  • Comments exist in your editor but vanish in the preview
  • @due(date) is native deadline syntax, not a plugin
  • .mrld files are plain text — readable anywhere, even without RubyNotes
